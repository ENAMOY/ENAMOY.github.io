08 可拉的叛乱 (民数记 16:1-17:13)

经文范围

民数记 16:1-17:13

经文背景

窥探迦南事件后，以色列人面临四十年漂流的判决。在这个背景下，可拉和他的同党起来叛乱，挑战摩西和亚伦的权柄。这是以色列人旷野时期最严重的叛乱之一。

经文分段

第一段：可拉党的叛乱（16:1-11）

叛乱者（16:1-3）：

  • 可拉是利未人（哥辖的子孙）（16:1）
  • 大坍、亚比兰是流便人（16:1）
  • 安和以色列会中的二百五十个首领（16:1-2）
  • 聚集攻击摩西和亚伦（16:3）
  • "你们擅自专权！全会众个个既是圣洁，耶和华也在他们中间，你们为什么自高，超过耶和华的会众呢？"（16:3）

摩西的回应（16:4-7）：

  • 摩西俯伏在地（16:4）
  • 明天耶和华必指示谁是属祂的（16:5）
  • 可拉和同党要拿香炉来（16:6-7）
  • 耶和华会拣选谁

挑战利未人（16:8-11）：

  • 摩西对可拉说："利未人哪，你们听我说！"（16:8）
  • 神将你们分别出来办会幕的事（16:9）
  • 你们还要求祭司的职分吗？（16:10）
  • 你和你一党聚集是要攻击耶和华（16:11）

第二段：大坍和亚比兰的抗拒（16:12-14）

他们的抗拒（16:12-14）：

  • 打发人去召大坍和亚比兰（16:12）
  • 他们不肯上来（16:12）
  • 批评摩西：从流奶与蜜之地领我们出来（16:13-14）
  • "难道你要剜这些人的眼睛吗？"（16:14）

第三段：审判（16:15-40）

摩西的怒气（16:15）：

  • 摩西甚怒气（16:15）
  • "求你不要享受他们的供物"（16:15）

第二天的试验（16:16-18）：

  • 可拉和同党各拿香炉（16:17）
  • 各香炉里放火和香（16:17）
  • 站在会幕门口（16:18-19）

神的显现（16:19-22）：

  • 耶和华的荣光向全会众显现（16:19）
  • 神要灭绝他们（16:21）
  • 摩西和亚伦俯伏在地（16:22）
  • "一人犯罪，你就要向全会众发怒吗？"（16:22）

可拉党的审判（16:23-35）：

  • 耶和华吩咐会众离开可拉、大坍、亚比兰的帐棚（16:24-26）
  • 他们站在自己帐棚门口（16:27）
  • 地开口吞了可拉、大坍、亚比兰和他们的家眷（16:31-33）
  • 他们活活地坠落阴间（16:33）
  • 有火从耶和华出来，烧灭那献香的二百五十人（16:35）

香炉的处理（16:36-40）：

  • 把香炉从火中捡起来（16:37）
  • 锤出来包在坛上（16:38-39）
  • 给以色列人作记号（16:40）

第四段：百姓的怨言（16:41-50）

百姓的反应（16:41-43）：

  • 第二天全会众发怨言（16:41）
  • "你们杀了耶和华的百姓了！"（16:41）

瘟疫（16:44-50）：

  • 耶和华要用瘟疫击杀他们（16:45-46）
  • 摩西叫亚伦拿香炉为百姓赎罪（16:46-47）
  • 站在活人死人中间（16:48）
  • 瘟疫就止住了（16:48）
  • 死了一万四千七百人（16:49）

第五段：亚伦的杖发芽（17:1-13）

十二枝杖（17:1-7）：

  • 从以色列十二支派取杖（17:2）
  • 每支派一根，写上名字（17:2）
  • 亚伦的名字写在利未支派的杖上（17:3）
  • 放在会幕内法柜前（17:4, 7）

结果（17:8-11）：

  • 第二天亚伦的杖发了芽（17:8）
  • 生了花苞，开了花，结了熟杏（17:8）
  • 其余的杖没有变化

神的命令（17:12-13）：

  • 把亚伦的杖放在法柜前（17:10）
  • 给背叛的人作记号（17:10）
  • "这样，他们向我发的怨言就止息了"（17:10）
  • 百姓惧怕（17:12）
  • "我们死啦！我们灭亡啦！"（17:12-13）

神学主题

1. 权柄的来源

  • 摩西和亚伦的权柄来自神
  • 可拉党挑战神所设立的权柄
  • 神亲自印证祂所拣选的人

2. 祭司职分的独特性

  • 只有亚伦家族可以作祭司
  • 利未人有事奉会幕的职责，但不是祭司
  • 每个支派有自己的位置

3. 神的审判

  • 可拉党活活坠落阴间
  • 二百五十人被火焚烧
  • 一万四千七百人死于瘟疫
  • 神的审判是严肃的

4. 亚伦的杖

  • 杖发芽象征生命从死里出来
  • 表明神印证亚伦的祭司职分
  • 作为永远的记号

基督的预表

1. 亚伦的杖发芽 → 基督从死里复活 2. 香炉赎罪 → 基督为我们代求 3. 亚伦的祭司职分 → 基督是我们的大祭司 4. 神的审判 → 基督是审判者 5. 记号 → 基督是神的记号

今日应用

1. 尊重权柄：我们要尊重神所设立的权柄 2. 不要嫉妒：嫉妒导致叛乱 3. 神的审判是严肃的：不要轻忽神的审判 4. 基督的复活：亚伦的杖发芽预表基督的复活 5. 谦卑的事奉：每个信徒都有自己的位置
